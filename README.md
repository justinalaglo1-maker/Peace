## ✨ About
**PEACE’s DARK BOT** est un bot WhatsApp Multi-Device fait avec **Baileys**.  
Objectif : Rapide, stable, et avec une personnalité sombre mais cute.  
Créé par **Iron Peace** parce que les bots normaux c’est trop fade 🤧

---

## 🚀 Features
- 🔗 WhatsApp Multi-Device Baileys
- 🧩 Système de plugins facile à ajouter
- 💬 Boutons, Listes, Réactions
- 📥 Téléchargement TikTok, YT, Insta
- 👥 Modération de groupe : kick, promote, anti-lien
- 🤖 Réponses perso + mode IA
- 🌙 Mode sombre + auto-react
- ⚙️ Mode Public & Privé

---

## 🛠️ Tech Stack
- Node.js v20+
- @whiskeysockets/baileys
- Express.js
